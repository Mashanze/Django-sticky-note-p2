# Django Sticky Notes Application (Part 2)

A fully-featured full-stack web application built with Django that allows users to create, view, edit, delete, and color-code their personal sticky notes.

---

## Features
* **Full CRUD Operations:** Create new notes, view existing ones in a responsive grid, edit note details, and delete notes.
* **Custom Color Themes:** Assign unique sticky note colors (`Light Cloud`, `Sunny Yellow`, `Mint Green`, `Soft Peach`).
* **Robust Unit Testing:** Comprehensive test suite covering models, views, and the complete CRUD lifecycle.
* **Responsive UI:** Styled using Bootstrap for a clean and modern user experience.

---

## Tech Stack
* **Backend:** Python, Django
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Testing:** Django TestCase Framework
